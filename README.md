## 💡 Key Concepts Learned

| Day | Concept | The "Why" Behind It |
|:---:|---------|---------------------|
| 01 | JVM & Bytecode | Java compiles to bytecode not machine code — each OS has its own JVM to run it. Write once, run anywhere. |
| 02 | public static void main | `public` → JVM can access it. `static` → no object needed. `void` → returns nothing. `String[] args` → command-line input. |
